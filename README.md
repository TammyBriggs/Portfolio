## ✨ Features

- Responsive single-page portfolio layout
- Smooth scroll navigation and active section highlighting
- Animated UI using ScrollReveal.js
- Toastify-powered form validation for:
  - Full name (Unicode, hyphens, apostrophes, spaces)
  - Email format validation
  - 10-digit phone number check
  - Required fields
- Contact form that submits to Google Sheets using a deployed Apps Script
- Downloadable resume
- Project showcase with live links and images
- Social media integration and contact options

---

## 🛠️ Technologies Used

- **HTML5** / **CSS3** / **JavaScript (ES6)**
- **Toastify.js** for notification popups
- **ScrollReveal.js** for animation on scroll
- **Google Apps Script** for backend form handling
- **Boxicons** for iconography
